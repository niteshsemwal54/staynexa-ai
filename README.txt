FREE PUBLISHING WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository named staynexa-ai.
2. Upload the CONTENTS of this website folder (index.html, styles.css, PDFs, assets folder) to the repository root.
3. Open repository Settings -> Pages. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
4. After GitHub publishes the site, the URL is usually https://YOUR-USERNAME.github.io/staynexa-ai/ . Use the exact URL shown in Settings -> Pages.
5. Send the real URL so the website link can be inserted into the startup profile and brochure PDFs.
